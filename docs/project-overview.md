# 프로젝트 개요

교회 수련회 게임 정보를 온라인에서 공유하고, 나중에는 자체 개발 게임과 사용자 게임을 사고팔 수 있는 플랫폼.

- 아이디어: 진선 / 개발: 나연 (AI 활용)
- 타겟: 전국 청년부 임원 → 이후 교회 다니는 사람 전체

## 기능 로드맵
1. **이미 만들어진 게임 리스트업 (1순위, 지금 하는 것)**
   - 블로그·유튜브·인스타그램에 공유된 게임 링크를 관리자가 큐레이션
   - 검색(관련 말씀, 태그 등) + 카테고리 필터
   - 게임별 팁 댓글 + 좋아요(추후 확장), 후기
2. **자체 개발 게임 판매**: 예산·나이·시간·두뇌/신체형 카테고리, 오프라인 PDF 키트, 온라인 게임 1인/1교회 판매, 무료 게임은 광고, 추후 교회 대항전(동시 접속 대비 필요)
3. **사용자 간 게임 판매** (중고나라형)
4. **로그인·개인화**: 외부 게임 책갈피, 찜 목록, 교회·이름·전화번호·이메일, 교회별 구매 히스토리와 추천

## 기타 검토 사항
- 책갈피 데이터에 관리자가 접근하려면 사용자 동의 필요 → 개인정보처리방침에 명시하고 가입 시 동의받기
- 모바일·태블릿 지원 (먼저 반응형 웹, 이후 PWA)
- 관리자 페이지 별도 제작
- "신천지 금지" 표시
