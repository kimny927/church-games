# 개발 계획 (1단계: 게임 리스트업)

## MVP 범위
- 포함: 게임 목록(카드형), 검색·카테고리 필터, 상세 페이지(요약·원본 링크·준비물·말씀), 팁 댓글 + 좋아요, 후기(별점 + 짧은 글), 카카오 로그인, 관리자 페이지(등록·수정·큐레이션 상태·댓글 숨김), 신천지 금지 안내, 약관·개인정보처리방침
- 나중에: 찜/책갈피, 교회 정보, 판매·결제·광고, 사용자 판매, 교회 대항전

## 일정 (준비 기간 제외 약 5주)
- [x] 0주차: GitHub 저장소 생성
- [ ] 0주차: Vercel·Supabase·카카오 디벨로퍼스 가입, 노션 게임 DB에 게임 30~50개 수집, 서비스 이름 임시로 정하기
- [x] 1주차: 프로젝트 뼈대 (목록·검색·필터·상세, 샘플 데이터)
- [ ] 1주차: Vercel 자동 배포 연결
- [ ] 1주차: Supabase 연결, 노션 게임 데이터 옮겨오기
- [ ] 2주차: 목록·상세를 실제 데이터로, 검색 개선
- [ ] 3주차: 관리자 페이지, 링크 입력 시 썸네일·제목 자동 가져오기
- [ ] 4주차: 카카오 로그인, 팁 댓글 + 좋아요, 후기
- [ ] 5주차: 모바일 점검, 약관·개인정보처리방침, 지인 10~20명에게 먼저 공개

## 확장 대비 설계
- 게임 테이블의 `kind` 필드(외부 링크 / 자체 판매 / 사용자 판매)로 2·3단계 게임을 같은 목록에 섞을 수 있게 함
- 회원 테이블에 교회·전화번호 칸을 미리 두되 4단계 전까지 받지 않음
- 결제: 토스페이먼츠 또는 포트원 / 광고: 구글 애드센스, 카카오 애드핏 / 대항전: Supabase Realtime 검토
