# 결정 기록

새 결정을 내리면 위에 추가합니다. (날짜 · 결정 · 이유)

## 2026-11-11
- **자동 스크래핑(GitHub Actions)은 MVP 이후로.** 5주 일정에 넣으면 로그인·댓글·후기가 밀린다. 첫 공개는 진선이 큐레이션한 30~50개와 반자동 수집(링크 입력 시 메타데이터 자동 추출)으로 충분하다.

## 2026-11-10
- **기술 스택: Next.js + Tailwind + Cloudflare Pages/Workers + Neon PostgreSQL + Firebase Storage + GitHub Actions.** 완전 무료로 시작할 수 있고 광고를 포함한 상업 사용이 가능하다. 비용은 트래픽이 늘 때만 생긴다. (2026-10-31의 Supabase + Vercel 결정을 대체)
- **콘텐츠 수집은 반자동(A)과 자동 스크래핑(B)을 함께 지원.** 반자동은 품질 관리가 쉽고, 자동은 콘텐츠를 풍부하게 만든다.
- **초기 심의 방식은 수동 승인.** 자동 수집 콘텐츠는 `pending`으로 저장하고 진선이 승인해야 노출한다. 소스별로 자동 승인을 켤 수 있지만 품질 관리가 먼저다.

## 2026-10-31
- **코드 작업은 로컬 터미널의 Claude Code에서, 변경은 PR로 리뷰 후 병합.** AI가 바로 main에 올리면 빠르지만 판단·리뷰할 기회가 없어 AI-Native Engineer 역량을 키우기 어렵다.
- **기술 스택: Next.js + Tailwind + Supabase + Vercel.** 무료로 시작 가능, AI가 잘 다룸, 결제·광고·실시간 기능을 나중에 붙이기 쉬움. (→ 2026-11-10에 변경)
- **1단계 MVP는 외부 게임 리스트업만.** 판매·대항전은 사용자와 콘텐츠가 모인 뒤에.
- **댓글·후기는 로그인 사용자만(카카오 로그인).** 신천지 등 악성 사용자 차단에 유리.
- **외부 게임은 요약 + 원본 링크로만 소개.** 원본 복사는 저작권 문제.
- **협업 문서는 노션.** 진선은 워크스페이스 멤버가 아닌 페이지 게스트로 초대 (멤버가 2명 이상이면 무료 블록 한도가 생김).
